# 内容覆盖说明

网站提供 6 个课程模块、31 节课程、10 个可执行 SQL 实验、42 个概念自测、3 个综合案例（14 个任务）和 4 组上机练习（32 个任务）。

| 来源 | 整理内容 |
| --- | --- |
| 第1章 数据库技术基础.pdf | DB/DBMS/DBS、数据管理发展、数据模型、E-R 基础、三级模式与映像 |
| 第2章+关系数据库的理论基础.pdf | 关系、各种码、集合运算、选择、投影、连接、除法 |
| 第4章+SQL基础1-48.pdf 与 第4章 SQL基础1-87.pdf | 合并重叠内容，整理数据定义、约束、索引；查询、视图与数据操纵结合考试重点补充 |
| 第5章 关系数据库规范化理论.pdf | 函数依赖、属性闭包、候选码、1NF/2NF/3NF、BCNF 概念、规范化分解 |
| 第6章 PL-SQL编程基础1-45.pdf 与 第6章 PL-SQL编程基础.pdf | 合并重叠内容；变量、控制流、异常、游标、过程、函数、触发器 |
| 考试重点.pdf | 第7章设计流程、E-R 转换、闭卷综合题方向、复杂查询及编程 |
| 上机4(1).docx 与 上机4.sql | 基建 4 题、快递 3 题；按题目完整补足查询和建模 |
| 上机5(1).docx 与 上机5.sql | 销售管理 5 题；按产品总销量比较，保留并列 |
| 上机6(1).docx 与 上机6.sql | 图书 12 题、图书游标 3 题、材料库存游标 1 题 |
| 上机7-8(2).docx 与 上机7-8.sql | 基建过程/函数 2 题、电商过程 2 题 |

课程解释是重新组织的教学内容。原始 PDF、Word 和个人 SQL 不进入发布目录或 GitHub 版本。上机数据采用匿名演示姓名和证号；题目要求“自己姓名”时，可在自己的数据库中替换。

课件与上机材料使用不同数据库方言，代码块明确标注，避免混用。题意有多种合理解释时，参考答案给出采用的假设，例如客户价格平均口径、单次图书种类本数、一天内归还的时间定义。

参考解法做了逻辑核对；SQL 实验的通用查询可自动测试。Oracle PL/SQL 和 MySQL 存储程序需在对应真实数据库中运行，网站实验引擎不能证明这些存储程序已通过数据库编译。
